# 硬件与系统仿真规格（docs/simulation）

《从电平重建互联网》的**可实现的仿真契约**。本目录是"规格 + 参考实现 + 验证报告",
不包含主工程代码;主工程由技术负责人按本规格实现。

## 1. 一句话结论

- **8 个主层 / 11 个子层**(L0a、L0b、L1–L5、L6a–L6c、L7)。
- **26 种器件**,其中 22 种有参考实现并通过 29 个用例;4 种(D15/D21/D22/D26)只有规格。
- **确定性由整数 tick + `(tick, seq)` 全序 + 传输/惯性延迟保证**,不是"靠帧率对齐"。
- **能跑多少**:GDScript ≈ 200 门 / 200 DFF;GDExtension ≈ 10,000 门 / 8000 DFF
  (60 FPS、5 ms/帧、4 tick/帧)。这些是**估算**,必须用工程内基准关校准(6 第 6 节)。
- **三处不建议硬做**:门级全展开 CPU、真 TCP/IP、游戏内"安全加密"(见 09)。

4. 任何标 ⬜ 的器件在补齐测试前,**不得**在 UI 声称"已真实仿真"。

## 5. 诚实声明(摘要)

- L0a(模拟电平)与 L7(真实主机桥接)是**简化/代理**,不是全保真,已逐条标注。
- CRC-8 ≠ CRC-32;TCP-lite 无对端 ACK、无拥塞控制;RSA/Feistel/OTP 均**不安全**。
- 亚稳态默认"违例即 X",不建模概率分布;总线**禁止**"最后写的赢"。
- 存储器是**宏单元**,不是门级 SRAM;ALU 的加法部分用门级行波,但整体是结构级。
- 所有简化及其对教学的影响,集中在 04 第 7 节、05 第 8 节、09 三张表里。
