## 6. 动效

| 事件 | 时长 | 缓动 | 备注 |
|---|---|---|---|
| 抽屉展开 | 200 ms | `TRANS_CUBIC / EASE_OUT` | 只动高度；内容在 t=200 ms 整块出现，不做 alpha 渐变 |
| 抽屉收起 | 140 ms | `TRANS_CUBIC / EASE_IN` | 内容先收，高度后收 |
| 箭头翻转 | 200 ms | `steps(4, end)` | 0° → 90° |
| 行 hover | 90 ms | `steps(2, end)` | 底 α.06 + 边 α.32 |
| 购买成功 | 120 ms | `steps(2, end)` | 角标 +1 立即；行边白 α.40 → 0 |
| 绑定斜纹 | 0 | 静态 | 不参与动画 |

`M` 关闭动效后：展开/收起瞬切，hover 无过渡，购买无描边闪烁。

## 7. 为什么「插座式抽屉」优于平铺网格

1. **屏数**：12 层 × 平均 2.3 件 ≈ 28 行 + 12 个层头，按 56 行高 / 8 间距 = 2128 px，视口 448 → **4.7 屏**。平铺必须跨屏滚动才能比价。
2. **比价路径**：抽屉把「入口（2 个）→ 层（12 个）→ 件（≤3 行）」压成三级；同一时刻只有一层可见，价格 x=310、按钮 x=470/562 在所有层完全一致，比价是**横向扫视**；平铺的纵向长列表需要记忆上一屏价格。
3. **位置稳定**：抽屉的入口顺序与层号固定，不随库存变化重排；平铺买入后角标变化会触发重排，破坏位置记忆。
4. **收起态即决策**：收起态 56 px 内保留「层号 + 件数 + 价格带」，一屏 2 个入口就能回答「今天买元件还是买配方」，不展开也能做第一层决策。
5. **不堆砌**：展开只增加高度，不增加新面板、新标题、新说明文字；层头本身就是索引，不另写导航提示。
