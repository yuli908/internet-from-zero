# 05 · 知识树：树形布局与节点文字承载

> 基准 1280×720。树视口 `(260, 120, 996, 538)`，底边 704。节点 94×44（实现侧实测尺寸）。
> 字号：`F_BODY 18` / `F_LABEL 16` / `F_CAPTION 15` / `F_META 14`（1280 下最小物理 18 px）。

## 0. 结论

1. **6×6 方阵撑不住树**，弃用。方阵中相邻格等距，连线只能横穿多格，无法表达「谁依赖谁」；幕间 104 px 只能切 3 幕，切不出同幕内的父子关系。
2. 改为 **三幕横带**：每幕一条横向主线链（M→K→K→M→K→K），分支从知识节点向下挂 16 px 竖枝，7 个挑战收进底部外环，终章接在外环末端。
3. 节点内只放 **编号 + ≤5 字短名**；完整副标题在 hover 260 ms / 键盘焦点时以浮条出现，选中后进左栏「当前节点」块。
4. 代价如实记录：节点净覆盖 44.4%（旧 118×46）→ **30.3%**；换回的是「主线满行、分支有父、挑战成环」的可读结构。

## 6. 节点内文字

| 位置 | 内容 | 字号 | 长度上限 | 超限规则 |
|---|---|---|---|---|
| (6, 5) | 编号 | `F_META 14` | 3 字位 | 固定编号，不截断 |
| (6, 22) | 短名 | `F_LABEL 16` | **5 字** | 第 6 字起省略，取前 4 字 + 「…」；不换行、不缩字号 |

编号规则：主线里程碑 `1`–`6`、知识 `1.1`–`6.3`、分支 `B1`–`B9`、挑战 `C1`–`C7`、终章 `END`。
短名规则：里程碑取实验名（「电平」「二进制」「布尔」「门级」「时序」「半加器」）；知识取 ≤5 字核心词（「阈值」「位权」「真值表」「德摩根」）；分支取技能名（「测量」「封装」「排错」）；挑战 `挑 1`–`挑 7`；终章 `终章`。
宽度校验：5 字 × 18 px = 90 px + 左右 12 px = 102 px > 94 —— 因此短名按 **5 个汉字位** 计算时字号回落 `F_LABEL 16`：5 × 16 = 80 px + 12 = 92 ≤ 94。

## 8. 为什么这不违反「少加文字」

- 浮条与「当前节点」块都是**条件显示**：不选中 = 0 条，选中 = 1 条，不进入常驻上限（见 `06 §5.1` 条件显示条款）。
- 节点内只有编号 + 短名，属实体数据；副标题属教学，只在需要选路时出现。
- 36 个节点同时可见时，屏上常驻说明性文字 = 3 条幕注，其余全是 ≤5 字的词。
