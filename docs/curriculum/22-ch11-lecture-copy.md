## 0.1 三条接缝（写进正文，不是建议）

**接缝 1：11.1 的 16 条就是 5.2 和 02 §7.5 的那张表，不另造指令集。**
机器码固定 16 位 `[OPCODE 8b][OPERAND 8b]`，助记符只是这张表的可读名字；不换字长、不加码位。违反了会出什么事：5.1 的控制表与 5.2 的单步全部对不上，P01 变成另写一套汇编器。

**接缝 2：11.2 的跳转只看 5.1 已有的 Z/C，PC 按字节步进这条规矩照旧。**
条件标志是 ALU 的副产物，不为循环新开标志，也不把 PC 改成按指令条数步进。违反了会出什么事：5.2 的 ADD/SUB 与 11.2 的 JZ/JC 各说一套，循环退出条件无处可查。

**接缝 3：11.3 的调用约定照 02 §7.5：A/B 传参、返回地址压 `MEM[0xF0..]`、Z/C 不跨调用保存。**
本文件不另立约定，也不给 16 条表外加指令。违反了会出什么事：11.3 的栈与 12.3 的栈帧各按一套布局，返回地址检查失去基准。

| # | 实践 | 级别 | 玩家做出什么 | 机器怎么判他做对了 | 失败落在哪个 code |
|---|---|---|---|---|---|
