# 教学资产清单

> 用途：给美术、动画、程序、关卡设计排期。资产按"缺了它这节课就上不成"排序，不按"好看"排序。
> 范围：第一章逐节细化（48 项）；第 2–14 章为首轮需求（53 项）；通用组件（6 项）。合计 **107 项**。
> 说明：第 2–14 章仅列关键资产，节级细化待对应章节脚本完成后补；本清单不把"待细化"写成"已完成"。

---

## 1. 优先级与生产规范

### 1.1 优先级定义

| 级别 | 定义 | 排期规则 |
|---|---|---|
| P0 | 缺了这节课无法讲/无法验收（核心图、核心交互、核心题） | 第一批，先于关卡 |
| P1 | 显著影响理解效率，但有文字替代方案 | 第二批，与关卡同步 |
| P2 | 提升氛围/复用/进阶理解，可延后 | 第三批，按余量 |

### 1.2 通用生产规范

| 项 | 规范 |
|---|---|
| 基准分辨率 | 1920×1080；安全区四周留 48px；支持 16:10 与 21:9 |
| 字号 | 图内标签 ≥18px；关键数值 ≥24px；支持 125%/150% 缩放 |
| 线宽 | 主线条 2px，辅助 1px；不用细于 1px 的线表达逻辑 |
| 配色 | 低饱和硬朗风；高/低、正确/错误用"颜色+形状+文字"三通道，不单靠颜色 |
| 动画 | 单段 3–8 秒；循环动画可暂停；闪烁频率 <3Hz；提供"减少动态"开关 |
| 文本 | 所有文字外置可本地化；禁止把关键文字画进贴图；中英预留 30% 宽度 |
| 交互 | 键鼠/手柄可完成；拖拽必须有"点选→点放"替代；所有模型可重置 |
| 性能 | 单个交互动画 ≤2ms/帧脚本开销；同屏动画 ≤3 个；不用实时全局光照 |
| 可访问性 | 屏幕阅读器可读的目标条；色盲模拟通过；动态敏感模式可用 |

### 1.3 交互模型规格模板（每个交互资产必须填）

| 字段 | 说明 |
|---|---|
| ID / 名称 | 唯一编号，与本文档一致 |
| 教学目标 | 对应 `LO`，一句话 |
| 玩家输入 | 可操作元素（开关、滑块、拖拽、输入框） |
| 模型输出 | 灯/波形/真值表/读数/得分 |
| 失败状态 | 明确列出（悬空、短路、越界、超时），以及是否阻断 |
| 反馈 | 即时视觉 + 一句短语；不直接给答案 |
| 重置 | 一键复位；复位不丢已解锁知识 |
| 埋点 | 输入序列、失败码、用时、提示级别 |
| 确定性 | 随机用例用固定种子，可复现 |
