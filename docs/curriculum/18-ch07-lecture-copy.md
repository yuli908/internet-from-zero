## 0.1 三条接缝（写进正文，不是建议）

**接缝 1：7.1 必须接住 1.5 与 6.2 的「什么时候采」。**
1.5 讲过「毛刺不可怕，怕在毛刺那一刻采样」，6.2 讲过响应与采样相位。7.1 段 2/段 4 把它们收成一句「在正确时刻看对电平」。违反了会出什么事：7.1 退化成「速率调低点就不出错」的经验题，7.3 的 30% 偏移失去来处。

**接缝 2：7.2 的帧必须一路用到 7.4 的字节。**
7.2 段 3 定死 4 位数据帧；7.4 段 3 明说「一个字节拆两帧」。违反了会出什么事：7.4 临时换一套没讲过的帧，7.2 的帧蓝图变成摆设，7.3 的收发器也不知道自己在装什么。

**接缝 3：7.4 只讲两台机互通，不许抢 8.x 的分层与握手。**
7.4 只做「同频、共地、字节对、坏帧拒收」。分层、封装、ACK/超时留给 CH08。违反了会出什么事：8.1/8.2 又要从「两台机怎么连」讲起，而 7.4 真正的验收（9600 下字节正确）被挤没。

**怎么让他「能失败」**：①只接发送不接接收（3，单向都收不到）；②两端分频差 30%（10，第一帧碰巧对，第二帧开始错）；③不接校验（10，噪声帧被当数据——只有注入才暴露）。first-fail 顺序 3 → 13 → 10。

**需技术侧扩接口：双机端到端判据（两端位宽 + 双向字节逐帧比对 + 坏帧拒收帧号） / 最小替代：`byte_check` 同型扩参，输入两端 `tx_bytes` / `rx_bytes` / `frame_index`，逐帧比对并核对拒收帧号。**

**需技术侧扩接口：线缆噪声注入（按帧翻位、可复现） / 最小替代：在线缆模型上对指定帧的指定位做一次确定性翻转，用同一配置跑两遍结果一致。** 无噪声注入时，C 条退化为人工走查，**不得**用「随机出错」冒充。
