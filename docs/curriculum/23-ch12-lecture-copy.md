## 0.1 三条接缝（写进正文，不是建议）

**接缝 1：12.x 的编译产物必须落在 11.x 的 MUD-8 表内，不另造指令集与字长。**
输出仍是 16 位一条 `[OPCODE 8b][OPERAND 8b]`、8 位数据、256 B 地址、PC 按字节步进；P03 只负责「表达式 → 这 16 条表内指令」，不新增操作码。违反了会出什么事：11.1 手工汇编、11.2 跳转与 12.1 的指令序列各说一套，P01 与 P03 两个产出互相对不上。

**接缝 2：12.3 的调用约定照 11.3 与 02 §7.5：A/B 传参、返回地址压 `MEM[0xF0..]`、Z/C 不跨调用保存。**

**接缝 3：12.5 的字符处理照 6.1：字符先编码成字节（ASCII 单字节 / UTF-8 多字节），终止符与显存解码同 6.1。**
