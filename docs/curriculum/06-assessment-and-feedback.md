# 评估与反馈：小测、错因、提示、跳过与救援

> 目标：让评估服务于"学会"，而不是服务于"筛人"。
> 前提：本游戏允许失败、允许重试、允许跳过；但**不允许假装掌握**。

---

## 1. 评估层级

| 层级 | 频率 | 形式 | 作用 | 是否影响主线 |
|---|---|---|---|---|
| 微评估 | 每次操作 | 即时视觉反馈（灯亮/不亮、探针读数、黑盒用例） | 纠正操作，不打断思考 | 否 |
| 节评估 | 每节结束 | 5 道验收题（`03` 中的 1–5） | 判定本节 `LO` 是否达成 | 否（标记待补） |
| 章评估 | 每章结束 | 12 题小测（蓝图见下） | 判定章节通关、定位错因 | 通关线 70，不硬锁 |
| 跨章评估 | 每 3–4 章 | 综合项目/排障任务 | 检查迁移与遗忘 | 影响"精通"徽章，不锁主线 |

**原则**：微评估可以即时且高频；概念评估必须延迟，给玩家"再想一次"的机会。

---

## 2. 章节小测蓝图

每章 12 题，固定配比：**记忆 2 / 理解 3 / 计算 3 / 搭建 2 / 调试 1 / 开放 1**。
第一章的 12 题已逐题写出（见 `02-chapter-01-teaching-script.md` 第 2 节）；其余 13 章按同一蓝图出题，合计规划 **168 题**，本批次未逐题写出，不虚报为"已完成"。

### 2.1 评分与通关

| 项 | 规则 |
|---|---|
| 满分 | 100 |
| 通关 | ≥70，且搭建题不得为 0 分 |
| 优秀 | ≥85，且开放题 ≥3 级 |
| 重测 | 允许 2 次/章，取最高；间隔 ≥10 分钟 |
| 引导通过 | 使用 L4 接管的题按 60% 计分，并标记"引导通过" |

### 2.2 掌握度模型（按 LO 累计）

| 状态 | 判定 | 含义 | 后续 |
|---|---|---|---|
| 0 未接触 | 无证据 | 还没学到 | 正常推进 |
| 1 接触 | 有尝试记录，未通过 | 见过，但不稳 | 本节复习 |
| 2 通过 | 无提示通过验收 | 达成 L4/L3 | 进入间隔复习 |
| 3 稳定 | 通过 + 3 天后变式题仍通过 | 可迁移 | 可解锁"精通"标记 |

**章节通关** = 本章 L2/L3 目标全为 2+，L4 目标 ≥70% 为 2+，章测 ≥70。
**不阻断**：未达标只标记"待补"，下一章仍可进入，但会在入口显示 3 道前置检查题（不计分，只做诊断）。

## 3. 错因分类

> 同一道错题可能对应多个错因；系统取"最具体、最可干预"的一个作为主错因，其余作为副错因记录。

| 码 | 名称 | 识别信号 | 典型例子 | 首选干预 | 不该做 |
|---|---|---|---|---|---|
| C1 | 概念误解 | 同类题反复错，且解释中出现错误因果 | "浮空就是 0"；"或就是二选一" | 换类比 + 反例 + 让玩家自己复现 | 重复讲同一定义 |
| C2 | 符号/约定混淆 | 计算对但图/表错，或极性反 | AND/OR 符号互换；正/负逻辑混用 | 对照卡 + 一题双表征 | 归因于"粗心" |
| C3 | 计算错误 | 步骤对、结果错；或位权错位 | `1011₂` 算成 12；漏进位 | 过程分步 + 边界练习 | 只让他"再算一遍" |
| C4 | 接线/操作错误 | 黑盒失败但表达式正确 | 输入悬空、输出并联、电源未接 | 探针逐点 + 故障库（`03` 0.5） | 直接给正确电路 |
| C5 | 测量/读图错误 | 读数与波形不符，探头接错 | 没接地、量程错、采样点错 | 示范一次正确测量 + 让他复测 | 认为是"原理没懂" |
| C6 | 调试策略缺失 | 随机改、换件、重开，不做二分 | 一错就重写全部 | 教"假设→验证→缩小范围" | 替他调好 |
| C7 | 前置缺失 | 卡在依赖概念上，且低阶题也错 | 不会进制却做真值表 | 回退到前置 `LO`，给 5 分钟微课 | 在原地硬讲高阶内容 |
| C8 | 审题/注意力 | 会做但漏条件，错因不稳定 | 漏看"至少两个"；漏一组输入 | 强制复述题意 + 检查清单 | 贴"粗心"标签 |
| C9 | 工具/环境 | 同一存档换机异常、工具不会用 | 不会用示波器触发、存档损坏 | 工具微教程 + 环境自检 | 归因于知识缺陷 |

### 3.1 错因记录规则

- 每题记录：`item_id`、`error_code`、`first_failure_step`、`hint_level_used`、`attempt_count`。
- 同一 `LO` 下连续 3 次 C1/C7，触发"前置回退"建议。
- C3 连续 3 次，触发"计算工作台"（逐步引导，不直接给答案）。
- C4/C5 连续 2 次，触发"工具微教程"。

## 4. 提示阶梯

> 核心：**一次只升一级**；每级至少间隔一次尝试或 30 秒；提示不是答案。

| 级别 | 名称 | 内容 | 触发 | 代价标记 |
|---|---|---|---|---|
| H0 | 无提示 | 只显示失败用例编号 | 默认 | 无 |
| H1 | 元认知 | "你检查过输入是否都有确定电平吗？" | 同一失败 2 次 | 无 |
| H2 | 概念 | 指向知识树节点 + 一句原理 | H1 后仍失败 | 记录 hint_used |
| H3 | 局部示范 | 换一个**不同**小例子演示方法 | H2 后仍失败 | 记录 hint_used |
| H4 | 分步引导 | 当前题的第一步/下一个动作 | H3 后仍失败或玩家求助 | 标记"引导" |
| H5 | 完整解 + 复盘 | 展示一种可行解，要求玩家复述并做变式题 | 明确求助/连续 4 次失败 | 标记"引导通过"，不计 L4 |

### 4.1 提示内容规范

1. **不直接说答案**：H1–H3 禁止出现最终电路/最终数值。
2. **指向证据**：提示必须让玩家"去看某个东西"（探针、真值表某行、波形），而不是"照我说的做"。
3. **一次一个变量**：不要同时说"检查电源、检查输入、检查门"。
4. **可关闭**：所有 H2+ 提示都可折叠，不遮挡操作区。
5. **可追问**：提示卡提供"为什么？"展开，展开后仍不上升到 H5。

### 4.2 何时不给提示（保护思考）

- 玩家正在主动尝试、状态在变化（接线、测量、翻知识树）——**不打断**；
- 玩家刚失败 1 次，且时间 < 60 秒——**不给**；
- 玩家在开放题中探索——只给量规，不给方向；
- 玩家明确选择"我在思考/别提示我"——60 秒内不再弹。

## 5. 反馈时机

| 类型 | 时机 | 方式 | 理由 |
|---|---|---|---|
| 操作性错误（短路、反接、悬空） | 即时（<0.5 秒） | 视觉 + 一句短语 | 危险/不可逆，必须立刻制止 |
| 计算错误 | 提交后延迟 10–20 秒 | "再看一遍" + 标出错行，不报答案 | 给自我纠正机会，形成"desirable difficulty" |
| 概念错误 | 本节结束后 | 错因卡 + 反例 + 微课 | 避免在操作中途灌理论 |
| 调试策略错误 | 下一次尝试前 | 提示"先假设，再测一点" | 教方法而不是给结果 |
| 开放题 | 24 小时后或同伴互评 | 量规评分 + 两条改进建议 | 降低"猜评分者喜好" |

**禁止**：在玩家操作中途弹出大段文字；在失败瞬间连续弹 3 个提示；用"错误！"红字刷屏。

## 6. 跳过策略

### 6.1 允许跳过的条件（满足任一）

1. 玩家主动点"我卡住了/跳过这题"；
2. 同一题完整尝试 ≥2 次，且已用到 H3；
3. 同一 `LO` 连续失败 ≥3 次，且总时长 > 该题中位数的 2 倍；
4. 该题不是"安全/危险操作"教学题。

### 6.2 跳过的后果

| 项 | 规则 |
|---|---|
| 主线 | **不阻断**，继续下一节/下一章 |
| 标记 | 该 `LO` 记为"未掌握（跳过）"，不计入精通 |
| 复习 | 进入错题本，3 天后以变式题重现；下一章入口做前置检查 |
| 徽章 | 不能获得"独立完成/精通"徽章，可获得"推进"徽章 |
| 补救 | 提供 5 分钟微课入口，不强制 |

### 6.3 不允许跳过的情况

- 安全/危险操作（短路、带电插拔、删档）；
- 第 1 章的 3 个锚点：LO-1.1（电平判断）、LO-1.7（真值表）、LO-1.10（半加器）。这 3 项允许"暂时跳过"，但**下一章入口的前置检查必须通过**，否则只开放复习关，不开放第 2 章建造关（这是唯一的软门槛，理由：缺这三项，后面所有电路内容都无法进行）。

## 7. "玩家卡住"的判定与救援

### 7.1 判定信号

| 类型 | 信号 | 初始阈值 | 说明 |
|---|---|---|---|
| 硬信号 A | 同一失败用例连续失败 | 3 次 / 90 秒 | 最常见、最可靠 |
| 硬信号 B | 无有效状态变化 | 120 秒 | 不算翻知识树、看提示的时间 |
| 硬信号 C | 同一提示反复打开 | 3 次 / 60 秒 | 说明提示没解决问题 |
| 硬信号 D | 输入抖动 | 同一元素 20 次点击 / 10 秒 | 可能是不知所措 |
| 硬信号 E | 反复离开任务区 | 3 次 / 5 分钟 | 回避行为 |
| 软信号 F | 用时 > 中位数 2 倍 | 动态 | 只触发"是否需帮助"询问 |
| 软信号 G | 进度条停滞 > 3 分钟 | 动态 | 需结合其他信号 |

**误判防护**：
- 探索行为（故意试错、反复测量）不算卡住，只记录不干预；
- 玩家在知识树/商店中停留，不计入"无状态变化"；
- 触发后只给**非模态的救援邀请**（角落提示"需要帮忙吗？"），不自动弹窗；
- 玩家可点"我在思考"，60 秒内不再询问。

### 7.2 救援阶梯

| 级 | 名称 | 动作 | 适用 | 话术示例 |
|---|---|---|---|---|
| R1 | 诊断探针 | 1 道 10 秒小题，判断是 C1 还是 C7 | 首次卡住 | "先答一个小问题：这个输入没接时，电平是确定的吗？" |
| R2 | 降阶任务 | 拆成更小步骤/更简单输入（如先只做 `0+1`） | R1 显示前置缺口 | "我们先只算 0+1，不算 1+1。" |
| R3 | 对照示例 | 给一个**不同情境**的完整小例 | R2 后仍卡 | "看这个例子：两个开关串联，灯什么时候亮？" |
| R4 | 分步接管 | 系统完成当前一步，玩家继续 | 连续失败/明确求助 | "这一步我帮你接好地下拉，你来测。" |
| R5 | 跳过 + 补课 | 标记未掌握，进错题本，给微课 | R4 后仍无进展 | "这题先放着，三分钟后我们换个方式再来。" |

### 7.3 救援原则

1. **先诊断，再救援**：不要一上来给答案；R1 的 10 秒题决定后面给什么。
2. **降阶而不是重复**：同一句话讲三遍没用，换小步骤。
3. **保留玩家动作**：R4 最多代做一步，且必须让玩家完成最后一步并验证。
4. **记录而不是羞辱**：救援记录只用于改进关卡，不在 UI 上显示"你卡了很久"。
5. **跳过要可回**：跳过的题在错题本中可随时重做，重做通过可升级为"掌握"。

## 8. 反馈文案规范

### 8.1 四条原则

1. **具体**：说"第 3 组输入 `A=1,B=1` 时 Carry 为 0"，不说"你再仔细看看"。
2. **非评判**：说"这个输入还没接默认值"，不说"你怎么又忘了"。
3. **可行动**：每条反馈附一个下一步动作。
4. **一次一件事**：不同时指出 5 个问题。

### 8.2 对照示例

| 差 | 好 |
|---|---|
| "错误！" | "`1+1` 这一组，Sum 应该是 0，现在亮了。" |
| "这么简单都不会？" | "我们先只看 `0+1` 这一组。" |
| "你的电路是错的。" | "第 3 组输入没通过；先测一下这个门的输入是不是悬空。" |
| "答案是 XOR。" | "哪个门在'两个输入不一样'时输出 1？去真值表里找那一行。" |
| "请重新学习本节。" | "这题先跳过；三分钟后用一道更小的题再试。" |

### 8.3 成功反馈

- 不滥用"太棒了"；用**具体证据**："你只用 3 个 NAND 就实现了 OR，和标准解一样少。"
- 对"多解"要给认可："你的解比参考多一级，但更直观；在可维护性上更好。"
- 对"险过"要提示："这次通过了，但第 7 组输入刚好在边界；下次试试随机用例。"

## 9. 数据埋点（供实现方）

| 事件 | 字段 | 用途 |
|---|---|---|
| `item_start` | item_id, lo_id, attempt_no | 计算用时/尝试 |
| `item_submit` | item_id, result, failed_case_id, duration | 正确率/失败分布 |
| `hint_open` | level, item_id, elapsed | 提示依赖度 |
| `hint_dismiss` | level, item_id | 提示是否打扰 |
| `stuck_trigger` | signal_type, threshold, item_id | 校准阈值 |
| `rescue_step` | R1–R5, item_id, outcome | 救援有效性 |
| `skip` | item_id, reason, lo_id | 跳过率与缺口 |
| `mastery_change` | lo_id, from, to, evidence | 掌握度曲线 |
| `quiz_submit` | chapter, score, item_scores, error_codes | 章测分析 |
| `review_result` | lo_id, days_since, result | 遗忘曲线/间隔复习效果 |

**阈值不是拍脑袋定死的**：以上 90 秒/120 秒/3 次均为初始值，上线后用 `stuck_trigger` 与 `rescue_step` 数据校准；若某关救援触发率 >40%，优先改关卡，不是改阈值。
