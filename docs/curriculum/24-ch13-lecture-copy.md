## 0.1 三条接缝（写进正文，不是建议）

**接缝 1：13.1 的字节码不是 11.x 的机器码，两条执行路线不合并。**
11.x 的 16 位指令 `[OPCODE 8b][OPERAND 8b]` 直接进 MUD-8 CPU；13.x 的字节码进栈式 VM，由 VM 逐条解释。两者只共享「指令 = 编号 + 操作数」的形式，**不复用操作码表、不换字长**。违反了会出什么事：P04 变成第二个汇编器，P01 与 P04 的操作码互相污染，终章选 P04 路线时找不到独立执行入口。

**接缝 2：13.2 的引用照 12.2 的地址口径：引用就是一个地址值。**
对象在堆上占一段连续字节，引用值等于对象起始地址；对象图里的边是地址，不是变量名。违反了会出什么事：13.3 的「可达」无从判断，GC 只能靠猜，回收时刻不可判。

**接缝 3：13.x 与 CH14 并列，都从 12.5 出发，不互相冒充。**
13.x 不讲词法/语法/求值，CH14 不讲字节码与 GC；两条路线各自完整，终章二选一。违反了会出什么事：「一次编写到处运行」与「解释执行」被混成一句话，P04 与 P05 的验收互相抵赖。
