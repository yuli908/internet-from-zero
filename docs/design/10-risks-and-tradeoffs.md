## 2. 三个最可能失败的点（用于对外汇报，也是评审重点）

1. **R3 内容生产黑洞**（概率最高）：19 章每章都要「教学 + 机制 + 关卡 + 用例 + 引导 + 经济 + 回归」7 件事，任何一章偷工都会在后续章节变成「教不动」。这是**最可能拖死项目**的一条。
2. **R2 仿真保真度/性能与调试工具**：如果波形、单步、首个异常刻做不出来，CH3/CH5/CH11 会变成「盲搭」。玩家不是被难度劝退，是被**看不见**劝退。
3. **R4 抽象层跳跃**：从「继电器门」到「CPU」再到「汇编」是三次认知跃迁，每一跃都可能砍掉一半玩家。若 CH4 与 CH11 的通过率不达标，整条主线就只剩硬核中的硬核。

> R1（网桥）虽然技术风险最高，但**有可用的降级方案**，不会让项目「失败」，只会让宣传语降级；因此它排在第四位。

## 3. 取舍清单

### 3.1 必须做（P0，砍了就不是这个游戏）

| 项 | 理由 |
|---|---|
| CH1–CH19 主线 + 终章 | 承诺本身就是「重建互联网」 |
| 电平/逻辑/时序 的真实仿真 | 硬核底线 |
| 波形视图（测延迟、看毛刺） | 无此则 debug 不可玩 |
| 技能树常驻 + 走过的路 | 产品约束 |
| 设计台（5 类对象） | 产品约束 |
| 测试台（四类判定） | 「可验收」的唯一实现方式 |
| 经济（买 vs 造 + 预算校验） | 核心玩法之一 |
| 存档（快照/迁移/校验和） | 「工程文件不能丢」 |
| 引导（三级提示 + 目标列表） | 新手活下来的唯一办法 |
| 真实网桥（或 ADR-05 降级） | 终章意义 |

### 3.2 可以后置（P1，做完主线再说）

- B01–B09 全部分支（除 B07 作为「路由器太贵」的经济缓冲，可提前）。
- C03–C07 挑战（C01/C02 与 CH1 强相关，保留）。
- CH13 Java / CH14 Python（若只保留 C 路线，终章仍可通）。
- 面板自定义（D2 的布局编辑，先只做接口槽位）。
- 点阵显示器（B03）。
- 多档难度 / 无障碍选项（发布后补）。
- 多语言本地化（先中文）。

### 3.3 会拖垮项目（明确不做，写进「拒绝清单」）

| 项 | 为什么致命 |
|---|---|
| SPICE 级模拟电路仿真 | 性能与复杂度双杀，且主线只需要数字电平 |
| 完整真实网络栈（IPv6/HTTP2/QUIC…） | 无限需求，教学价值边际为零 |
| 写实美术 / 3D 场景 | 与「几何+文字」语言冲突，成本 ×5 |
| 多人联机 / 玩家对战 | 服务器、同步、作弊，全部不在范围 |
| 手机端适配 | 交互与字号全部要重做 |
| 内核级完整操作系统 | B09 只做概念级（进程/文件/系统调用） |
| 三进制完整章节 | 只做 C01 挑战（15 分钟），不做章 |
| 磁盘/磁头/盘片物理 | 用 S08 磁带抽象替代 |
| GPU / 显卡 | 与主线无关 |
| 全语音配音 | 文本 + 波形足够；配音会綁死文案改动 |
| 剧情分支 / 角色养成 | 会稀释「机制即内容」的定位 |

## 4. 决策记录（ADR）

| ID | 决策 | 理由 | 代价 |
|---|---|---|---|
| ADR-01 | CH1 用**继电器**做门，CH2 才换 CMOS | ① 继电器「看得见、听得见」，最直观；② 让玩家先体会「慢/响/大」，才有换晶体管的动机；③ 降低 CH1 认知负荷 | CH1 的延迟数值偏慢（3 t），需在 CH2 明确「这是为了让你看见」 |
| ADR-02 | CPU 用 **8 位 MUD-8**（16 条指令、256 B） | 可在 140 min 内让玩家搭完并跑通；16 位会让 CH5 翻倍 | 后期服务器章需 H02 升级；已在 04 预留 |
| ADR-03 | 技能树与知识树**共用坐标**，不做两套 UI | 避免学两次导航；符合「无论场景怎么变，技能树始终存在」 | 知识卡展示空间受限，需靠折叠/滚动解决 |
| ADR-04 | 引导 = **Toplist 骨架 + 点状锚点 + 演示重放** | 08 §3 加权对比 3.00 vs 2.05；多解法与硬核接受度两项决定性 | 首次上手略慢于纯视觉引导（用 L3 8 秒演示补偿） |
| ADR-05 | 终章网桥优先「本机 TCP 127.0.0.1:7777」；**失败则降级**为「导出程序 + 本机运行 + 游戏内完整链路演示」 | 保证卖点可交付，不把项目绑在单点技术风险上 | 降级版少一点「魔法感」，但仍是真实程序真实输出 |
| ADR-06 | Java / Python 设为**选修** | 内容量控制（R3）；终章只需一种语言路线 | 少一部分「多语言」卖点 |
| ADR-07 | 经济用**固定价格锚 + 30% 回收 + 一次性产出** | 从结构上消除套利，而不是靠不断调参 | 「造」在部分小件上确实不如「买」，需要 UI 明示 |
