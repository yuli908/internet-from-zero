### 1.2 三条硬规则（避免经济与机制互相打脸）

- **E1 成品价规则**：L0 为锚点价；L1–L5 为「集成封装价」，**不由散件成本线性推导**（现实里一颗集成门就是比四个分立管子便宜）。
  → 因此「买成品有时比买散件更便宜」是**合法**的，甚至常常如此。
  → 例外：配方中标注 `(改)` / `(裁剪)` 的是**派生件**（如网卡改蓝牙、CPU 裁剪成单片机），视为独立件，价格按母件的 40%–60% 另计，不参与「P ≥ 最贵件」校验。
- **E2 自造规则**：自造 = 蓝图/配方已解锁 + 关键件**已在库**（不消耗）+ `0.7P` 现金 + 工序。
  → 「造」的价值 = 更早拿到（不必等商店解锁）、可定制/可重设计、批量省 30%、推进知识树。
- **E3 复用规则**：`permanent` 件不消耗（工具/整机/软件许可证）；`semi` 件可拆回 60%；`consumed` 件焊上即消失。
  → 整机（L3/L4）默认 `permanent`，这是后期大额投入不掉价的基础。
