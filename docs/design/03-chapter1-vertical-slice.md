- **范围**：CH01 全章 6 节，从「一块电池」到「半加器」。
- **不含**：晶体管（CH02）、任何自动布线/自动生成门、任何联网功能。
- **垂直切片完成的定义**：
  1. 新玩家从启动到拿到 `G12 半加器`，无需任何外部文档。

### 1.1 电平：一条线只有两种「安全」

- **时长**：12 min（教学 5 / 实践 7）
- **教学目标**：
  1. 电压是连续量，数字电路只承认两个**区间**。
  2. `0 / 1 / X` 三元判读，X 是「不许当数」的区间。
- **教学讲法（骨架）**：
  1. 一块 3.3 V 电池接一个灯泡：亮 / 灭，两态，无中间地带 → 这就是「二值」的物理来源。
  2. 但电压不是只能 0 或 3.3：把可调电源从 0 慢慢拧到 3.3，灯会「半亮」；数字电路不承认半亮。
  3. 引入判读：`V<0.8 → 0`、`V>2.0 → 1`、中间 → `X`。讲清「中间那段不是 0.5，是错误」。
  4. 只讲一句噪声：线有电阻、附近有干扰，若判读区间窄，噪声就会把 0 读成 1。**伏笔**，1.5 节回收。
- **玩家操作**：
  1. 从库中拖 `M01 电源` 与 `M09 指示灯`，连线（自动吸附提示）。
  2. 点开电源属性，拖动电压滑块 0.0 → 3.3，观察灯与判读条同时变化。
  3. 在 0.8–2.0 区间内停留，读判读条显示 `X` 与红色叹号。
  4. 把判读阈值滑块改成 1.0/2.0，再扫一遍，观察「X 区间变窄」（为 1.5 噪声埋直觉）。
  5. 按下 `验证`。
- **系统响应**：判读条实时显示 `V / 判读值 / 所属区间`；进入 X 时提示「此时下游器件会收到未定义值」。
- **产出物**：`M01 电源`（+1）、`M09 指示灯`（+1）、知识卡 `KN-ELEC-01 电平与判读`。
- **验收用例（机器判定）**：

| # | 设置 | 期望 |
|---|---|---|
| T1.1-1 | V = 0.20 | 判读 `0`，灯灭 |
| T1.1-2 | V = 3.10 | 判读 `1`，灯亮 |
| T1.1-3 | V = 1.65 | 判读 `X`，UI 显示未定义告警 |
| T1.1-4 | V = 0.85（阈值默认） | 判读 `X` |

- **常见错误 → 反馈**：把灯直接接电池两端却把电压设为 1.6 V 期待「半亮算 0.5」→ 提示「数字世界没有 0.5，只有 0、1 和错误」。

### 1.2 二进制：并排的开关，与「为什么不是三进制」

- **时长**：22 min（教学 10 / 实践 12）
- **教学目标**：
  1. 用 N 个二态开关表示 `0…2^N−1`，理解位权。
  2. 完成二/十/十六进制互转（4 位一组）。
  3. 能说出三进制「理论上更省、工程上更贵」的**具体理由**，而不是「二进制简单」。
- **教学讲法（骨架，重点）**：
  1. 先不提「进制」。给 4 个开关，问：能表示几种状态？答 16。**位权**自然浮现：`8 4 2 1`。
  2. 命名：这就是二进制。加标签：4 位一组叫十六进制（`0…F`），为了人读方便，不是机器需要。
  3. **「为什么不是三进制」用三个可量化指标回答**（禁止讲成哲学）：

| 指标 | 二进制 | 三进制 | 结论 |
|---|---|---|---|
| 单器件稳定态 | 继电器吸/放、MOSFET 截止/饱和，天然两态 | 需人为定义三态，器件本身没有第三稳态 | 二态**免费**，三态要**造** |
| 噪声容限（3.3 V 供电） | 低区 0.8 V、高区 1.3 V（禁带 1.2 V） | 三等分 → 每级容限 ≈ 0.55 V | 三态容限只剩 **42%**，误判率上升 |
| 单「位」信息量 / 单「位」成本 | 1 bit / 1 份 | 1.585 bit / ≈2.2 份（2 个比较器 + 窗检测 + 驱动） | 理论更省，**单位信息成本反而高约 39%** |
| 门实现代价 | 全加器 ≈ 5 个二输入门 | 三进制半加器需 2 比较器 + 2 选通 + 态检测 | 同功能器件数 **>2×** |

  4. 补一句诚实的史实：三进制计算机真的被造过（苏联 Setun，1958 年），它能跑，但在「器件、生态、容错」三项上打不过二进制 —— 不是不能用，是**不划算**。
  5. 收束：二进制赢**不是数学最优，是工程最便宜**。这也是本作的核心价值观。
- **玩家操作**：
  1. 用 4 个开关组成计数面板，按 `0…15` 逐个点出，右侧实时显示二进制与十六进制。
  2. 系统随机给一个十进制数（例 137），玩家用 8 个开关摆出，`验证`。
  3. 打开「进位实验」：点第 4 位（8）时观察 `0111 → 1000` 的连锁翻转。
  4. 可选：进入 `C01 三进制加法器` 挑战（入口在本节末尾，非必须）。
- **系统响应**：开关面板支持键盘 `0–9` 快速置位；错误时高亮差异位，不给答案。
- **产出物**：`M10 开关`（4 件）、`G? 开关面板子电路`（可复用件，进商店可买）、知识卡 `KN-BIN-01..04`。
- **验收用例**：

| # | 输入 | 期望 |
|---|---|---|
| T1.2-1 | 摆出 0…15 全部 | 16/16 正确 |
| T1.2-2 | 目标 137（8 位） | 摆出 `10001001` |
| T1.2-3 | 目标 0x2F | 摆出 `00101111`，且十进制 47 |
| T1.2-4 | 口头题（三选一） | 选「三态噪声容限更小、器件成本更高」 |

- **常见错误 → 反馈**：把 `1000` 读成「一千」→ 提示「这里的 1 在第 4 位，权值是 8，不是 1000」。

### 1.3 布尔：把「灯亮不亮」写成表

- **时长**：14 min（教学 6 / 实践 8）
- **教学目标**：
  1. 真值表是行为规格，不是数学作业。
  2. 与/或/非的真值表可由两个开关 + 一个灯直接验证。
  3. 末尾才引入符号 `∧ ∨ ¬` 与德摩根。
- **教学讲法**：
  1. 从「两个开关都闭合灯才亮」出发，写出 4 行真值表，命名为 AND。
  2. 并联 → OR；一个开关串一个常闭触点 → NOT（先讲物理，不讲符号）。
  3. 符号只作**速记**：`A∧B`、`A∨B`、`¬A`；明确「符号不产生新知识」。
  4. 德摩根：`¬(A∧B) = ¬A∨¬B`，用真值表 4 行当场验证（不做代数证明）。
- **玩家操作**：
  1. 在真值表编辑器中点出 4 行，与画布上的实物对照，`验证`。
  2. 按提示搭 AND / OR / NOT 各一组（继电器触点，1.4 节正式给配方）。
  3. 完成德摩根对照：左右两列真值表逐行一致才算过。
- **产出物**：知识卡 `KN-BOOL-01..03`，真值表蓝图（可在后续章节复用）。
- **验收用例**：

| # | 检查 | 期望 |
|---|---|---|
| T1.3-1 | AND 真值表 4 行 | 全对 |
| T1.3-2 | OR 真值表 4 行 | 全对 |
| T1.3-3 | NOT 2 行 | 全对 |
| T1.3-4 | 德摩根两列对照 | 4/4 一致 |

- **常见错误 → 反馈**：`¬(A∧B)` 写成 `¬A∧¬B` → 只标红第 2/3 行，让玩家自己看出差别。

### 1.4 与或非：用继电器把逻辑「焊」出来

- **时长**：18 min（教学 7 / 实践 11）
- **教学目标**：
  1. 逻辑门是**接线方式**，不是抽象符号。
  2. 三种门的物理原型：串联触点=AND、并联触点=OR、常闭触点=NOT。
  3. 能用已有门组合出任意指定真值表（XOR 为例）。
- **教学讲法**：
  1. 拆开一个继电器：线圈 + 常开 + 常闭，讲「电生磁、磁吸触点」。
  2. 两个常开**串联** = 两个都按下才通 → AND；**并联** → OR；用常闭 → NOT。
  3. 指出继电器的三个缺点（慢、响、费电、体积大），**明确告诉玩家 CH02 会换掉它**，让玩家愿意继续。
  4. 组合：`A⊕B = (A∧¬B) ∨ (¬A∧B)`，逐步搭。
- **玩家操作**：
  1. 领取 3 个继电器，按提示接线，分别验证 AND/OR/NOT。
  2. `验证` 通过后，系统授予 `G01/G02/G03`（**黑盒子电路件**，可放置、可展开看内部）。
  3. 自由搭建区：用 3 种门实现 XOR，`验证`。允许多种解（4 门版、5 门版、用 NAND 版）。
  4. 把 XOR 封装为子电路 `MY-XOR`（命名 + 端口确认），成为可复用件。
- **产出物**：`M08 继电器`、`G01 非门`、`G02 与门`、`G03 或门`、`G04 异或`、子电路 `MY-XOR`。
- **验收用例**：

| # | 检查 | 期望 |
|---|---|---|
| T1.4-1 | 三组门各自真值表 | 全对（AND 4/4、OR 4/4、NOT 2/2） |
| T1.4-2 | XOR 4 组输入 | 4/4，且输出在 ≤12 t 内稳定（3 级继电器门，3 t/级） |
| T1.4-3 | 封装子电路后再次测试 | 结果不变（封装不改变行为） |
| T1.4-4 | （可选）用 2 种不同结构实现 XOR | 2 种都通过（用于证明发散解法） |

- **常见错误 → 反馈**：用 `(A∨B)∧(¬A∨¬B)` 得到同或（XNOR）→ 提示「检查第 0 行：A=0,B=0 时你要 0 还是 1」。

### 1.5 信号：线不是理想导线

- **时长**：20 min（教学 8 / 实践 12）
- **教学目标**：
  1. 器件有延迟，信号要「走」过去。
  2. 不同路径延迟不同 → 毛刺（race）。
  3. 能用波形定位一次真实故障，并用一种手段修复（滤波/加延迟/改结构）。
- **教学讲法**：
  1. 打开波形视图，测 NOT 链：每级 3 t（继电器）。
  2. 讲扇出：一个输出带太多输入会「带不动」（用亮度/电压跌落显示）。
  3. 关键：**同一信号经不同长度路径到达同一门** → 短暂错误脉冲。用自己做过的 XOR 复现：A 从 0→1 时输出出现一次 1 t 的尖刺。
  4. 修复三选一：加 RC 滤波（B01 会展开）、均衡路径延迟、改结构消除竞争。本节只要求「能修好并解释」。
- **玩家操作**：
  1. 放探针，测 3 个点的到达时刻，`验证` 延迟表。
  2. 触发「毛刺实验」：仿真给出一次尖刺，波形上标红。
  3. 任选一种修复，重测直到尖刺消失。
  4. 回答 1 道选择题（毛刺成因三选一）。
- **产出物**：`G07 缓冲器`（可加延迟）、示波器功能解锁、知识卡 `KN-SIG-01..03`。
- **验收用例**：

| # | 检查 | 期望 |
|---|---|---|
| T1.5-1 | NOT 链延迟 | 报告 = 3 t/级，误差 0 |
| T1.5-2 | 毛刺复现 | 波形出现宽度 ≥1 t 的错误脉冲 |
| T1.5-3 | 修复后 | 连续 20 次切换无错误脉冲 |
| T1.5-4 | 成因选择题 | 选「不同路径延迟不一致」 |

- **常见错误 → 反馈**：只把时钟放慢 → 提示「慢不能消除竞争，只会在别的输入组合上再出现」。

### 1.6 半加器：第一章的产物

- **时长**：14 min（教学 4 / 实践 10）
- **教学目标**：
  1. 加法可以只由逻辑门完成：`S = A⊕B`、`C = A∧B`。
  2. 输出「和」与「进位」是两个不同含义的位。
  3. 自己的设计可以变成可购买/可复用的商品（第一次接触经济闭环）。
- **教学讲法**：
  1. 二进制加法表 4 行（0+0、0+1、1+0、1+1），观察 `1+1=10` 的进位。
  2. 直接把真值表映射到门：和 = 异或，进位 = 与。
  3. 说明这只是一「位」，第二章会把它串起来变成 8 位。
- **玩家操作**：
  1. 放置 `G04 XOR` + `G02 AND`，共用一个输入分线。
  2. 接两个 `M09 指示灯`（S 与 C），逐组输入，`验证`。
  3. 封装 `G12 半加器`，命名，选择是否「上架到我的商店」。
  4. 章末：系统自动播放 15 秒「回顾」——从电池、开关、门到半加器的技能树点亮。
- **产出物**：`G12 半加器`（可复用/可购买/可上架）、金币结算、章末徽章。
- **验收用例（章末总 gate）**：

| # | 检查 | 期望 |
|---|---|---|
| T1.6-1 | 4 组输入 | S/C 全对（`1+1` → S=0, C=1） |
| T1.6-2 | 延迟 | 输出在 ≤12 t 内稳定（XOR 3 级 + AND 1 级，3 t/级） |
| T1.6-3 | 封装 | 子电路端口 = A/B/S/C，测试结果不变 |
| T1.6-4 | 章末总测 | 随机 8 组（含非法输入 X）行为符合 §7.1 判读规则 |
